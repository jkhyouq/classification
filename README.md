# classification - лассификация ОС по сетевым признакам

Описание проекта

Этот проект представляет собой модель машинного обучения, которая классифицирует операционные системы (Windows, Linux, Android, iOS, Mac OS) на основе сетевых признаков, таких как:

User-Agent

TLS (JA3 hash, ciphers, extensions)

TCP/IP параметры (TTL, MSS, Window Size)

HTTP/2 параметры

Основные этапы работы модели

1. Очистка данных

Перед обучением данные очищаются от шума:

Удаляются явные противоречия (например, User-Agent указывает Windows, а fingerprint схож с iOS).

Фильтруются лишние поля, оставляя только значимые признаки.

Данные записываются в cleaned_sample_data.json.

2. Обучение модели

Данные разделяются на тренировочные и тестовые выборки.

Применяется SMOTE для балансировки классов.

Используется XGBoostClassifier.

Логируется точность (Accuracy) и F1-score модели.

Модель и encoder сохраняются (model.pkl, label_encoder.pkl).

3. Классификация новых данных

Загружается обученная модель.

Применяется к новым данным.

Выводится ТОП-3 предсказания с уверенностью.

Ошибки сохраняются в errors.json, а уверенные ошибки штрафуются.

Запуск проекта

1. Очистка данных

python classify_os.py --clean

2. Обучение модели

python classify_os.py --train

3. Тестирование модели

python classify_os.py --test

Ошибки и их обработка

Ошибки модели логируются в errors.json. При следующем обучении ошибки используются для дообучения модели. Если модель уверенно ошибается (уверенность > 0.9), применяется штраф.
